TROUBLESHOOTING NOTES
=====================

If container build fails again:
1. Check Docker is running
2. Verify GitHub Container Registry login: docker login ghcr.io
3. Check backend builds locally: cd backend && dotnet build
4. Check frontend builds locally: cd frontend && npm run build

Common Issues:
- Missing .env files (use templates)
- Docker not authenticated to registry
- Package restore issues (clear NuGet cache)
- Path issues in Dockerfiles
