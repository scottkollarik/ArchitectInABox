============================================================
PART 1: IMPORTANT QUESTIONS TO ASK THE CLIENT
============================================================
WORKLOAD & TRAFFIC
What is the expected throughput (RPS/requests-per-second)?
Is traffic steady or bursty? What are peak vs. average RPS?
What are latency targets? (p95, p99 in milliseconds)
Geo distribution of users? Primary regions? Any data-residency needs?
Are requests idempotent? Any long-polling or streaming?
DATA & CONSISTENCY
Primary data model? (Relational, document, key-value, time-series)
Required consistency? (Strong, bounded-staleness, session, eventual)
Read/write ratio? Typical item/document size?
Expected data growth and retention policies? Archival requirements?
Transactions required across entities? (ACID scope)
Search, analytics, or reporting needs?
AVAILABILITY & RESILIENCE
Target SLA/SLO (uptime, latency)?
RTO (Recovery Time Objective) and RPO (Recovery Point Objective)?
Multi-region strategy: active-active or active-passive?
Zone redundancy required? What failure modes must be tolerated?
Acceptable behavior during failover (re-login, minor data loss)?
SECURITY & COMPLIANCE
Regulatory/compliance requirements (PCI, HIPAA, GDPR, SOC, FedRAMP)?
Data classification (PII/PHI/PCI) and encryption requirements (at rest/in
transit, customer-managed keys/HSM)?
Networking posture: private endpoints only, zero-trust, egress controls?
Identity provider and auth flows (Entra ID/OIDC/OAuth2, SAML)?
Secrets management and rotation cadence?
OPS, RELEASE, AND OBSERVABILITY
Preferred IaC tool (Bicep/Terraform/ARM) and CI/CD platform?
Release strategy (blue/green, canary, feature flags)?
Monitoring/alerting stack (Azure Monitor, App Insights, Log Analytics;
third-party like Datadog/Splunk)?
Log/metrics retention and budget limits for observability?
On-call model, escalation paths, error budgets?
COST & CONSTRAINTS
Budget priorities (optimize for performance, cost, or balance)?
Serverless autoscale-to-zero acceptable, or require always-on capacity?
Preferences/constraints: PaaS-first vs. AKS vs. VM-based?
Licensing, procurement constraints, required SKUs?
CHECKPOINT
What does success look like in 30/60/90 days? Any hard deadlines?
Non-functional “must haves” vs. “nice to haves”?

PART 2: AZURE APP IMPLEMENTATION PLAYBOOK (ADAPTABLE)
============================================================
GOAL: Provide a secure, resilient, and scalable default you can tailor to
different workloads. Swap compute/data choices as needed.
EDGE & SECURITY
Azure Front Door (Std/Premium): global anycast, WAF, TLS, health probes,
path routing, caching of static and cacheable API responses.
DDoS Protection Standard at vNet scope.
Key Vault for secrets/keys/certs; use Managed Identity everywhere.
Private Endpoints for all data services; no public DB endpoints.
NSGs/ASGs, Zero-Trust principles, minimal egress.
COMPUTE (CHOOSE ONE PRIMARY)
Azure Container Apps (PaaS, scale on RPS/concurrency/CPU; simple ops).
AKS (Kubernetes) when you need K8s primitives, sidecars, custom ingress.
App Service (Web/API) for the simplest web workloads.
Keep services stateless; store session in Redis.
STATE & ASYNC
Azure Cache for Redis: sessions, hot keys, rate limiting, feature flags.
Azure Service Bus (or Storage Queues): async jobs, retry, backpressure.
Event Hubs for streaming/telemetry if needed.
DATA LAYER (CHOOSE PER MODEL)
Relational/transactional: Azure SQL Database Hyperscale with read scale;
failover groups for DR; zone redundancy where available.
Document/kv/global: Azure Cosmos DB with multi-region reads/writes and
tunable consistency (often Session consistency for apps).
Object storage: Azure Blob Storage for files, images, logs; lifecycle
policies for cost control; optional CDN via Front Door.
Search/analytics (optional): Azure Cognitive Search, Synapse/Databricks
for ETL/ELT and analytics pipelines.
OBSERVABILITY
Azure Monitor + Application Insights + Log Analytics for metrics, traces,
logs. Enable distributed tracing (W3C traceparent).
Dashboards for SLOs (latency p95/p99, error rate, saturation).
Alerting on SLO burn rate, queue length, autoscale limits, dependency
failures. Budget alerts for logs/metrics ingestion.
AVAILABILITY, SCALING & DR
Zone-redundant where supported (compute, cache, databases, gateways).
Active-active across two paired regions behind Front Door when required.
Autoscale policies:
* RPS or concurrent requests per replica (target window: 100–150 RPS).
* CPU utilization threshold (60–70%).
* Queue length and time-in-queue thresholds for async workers.
Backpressure:
* Shed load early (WAF rules, 429 with Retry-After).
* Queue non-critical work; idempotent consumers.
DR: SQL with failover groups; Cosmos multi-region; regular failover tests.
Chaos and load tests pre-production and periodically thereafter.
SECURITY BASELINE
WAF at Front Door (and/or App Gateway if used).
Identity: Entra ID (OAuth2/OIDC), RBAC/ABAC; Managed Identity for intra-
service auth; no embedded secrets.
Data encryption in transit (TLS 1.2+) and at rest (platform + CMK/HSM as
required). Key rotation via Key Vault.
Network: Private Endpoints, NSGs, no inbound to data subnets; egress
allowlists; proxy outbound if needed.
Supply chain: signed images, private container registry with scanning,
pinned base images, SAST/DAST in CI.
DEPLOYMENT & LIFECYCLE
Infrastructure as Code (Bicep/Terraform). GitOps optional for AKS.
CI/CD (GitHub Actions/Azure DevOps) with environments and approvals.
Deployment strategies: blue/green or canary; automatic rollback on
health check or SLO regression.
Feature flags for safe releases; database migrations with backward-
compatible steps (expand → migrate → contract).
PERFORMANCE & COST LEVERS
Cache-first reads; use TTLs and cache busting patterns.
Compress payloads; paginate; prefer gRPC/HTTP/2 for low-latency APIs
between services where appropriate.
Batch/async non-critical work; CQRS (read/write split) where useful.
Right-size compute; consider spot/consumption tiers for workers.
Set daily budget alerts; tune log sampling and retention.
SIZING RULES OF THUMB (MENTAL MATH)
Concurrency ≈ RPS × p95 latency (in seconds).
Rough vCPU throughput: ~100 RPS per vCPU for lightweight API work.
Containers needed ≈ total RPS ÷ per-container RPS capacity.
Keep 30–50% headroom for spikes and failover; design for N+1 zone.
CHECKLIST TO ADAPT THE PLAYBOOK
Swap compute: Container Apps ↔ AKS ↔ App Service based on control needs.
Pick data store per model: SQL for strong relational; Cosmos for global
document/kv; Blob for objects; add Search/Analytics as needed.
Tighten security per compliance: Private Endpoints, CMK/HSM, extra WAF
rules, egress proxying, Just-In-Time access.
Tune autoscale and caching after load tests; set SLOs and alerts.
Verify DR: region failover rehearsal; ensure RTO/RPO are met.
Document runbooks (incident, rollback, key rotation, failover).

active-active across paired regions where required, with Private Endpoints,

observability via App Insights and Log Analytics, and we load/chaos test

Rate Limiting Implementation
RateLimitPolicies.cs:
csharp
public static class RateLimitPolicies
{
    public static void ConfigureRateLimiting(this IServiceCollection services)
    {
        services.AddRateLimiter(options =>
        {
            // Tiered rate limiting based on endpoint criticality
            options.AddFixedWindowLimiter("Architecture", policy =>
            {
                policy.PermitLimit = 10;              // 10 requests
                policy.Window = TimeSpan.FromMinutes(1); // per minute
                policy.QueueProcessingOrder = QueueProcessingOrder.OldestFirst;
                policy.QueueLimit = 5;                // 5 queued requests
            });
            options.AddTokenBucketLimiter("Pricing", policy =>
            {
                policy.TokenLimit = 20;               // 20 tokens
                policy.QueueProcessingOrder = QueueProcessingOrder.OldestFirst;
                policy.QueueLimit = 10;
                policy.ReplenishmentPeriod = TimeSpan.FromSeconds(30);
                policy.TokensPerPeriod = 10;
            });
            // Global fallback
            options.GlobalLimiter = PartitionedRateLimiter.Create<HttpContext, string>(
                httpContext => RateLimitPartition.GetFixedWindowLimiter(
                    partitionKey: httpContext.User.Identity?.Name ?? httpContext.Request.Headers.Host.ToString(),
                    factory: partition => new FixedWindowRateLimiterOptions
                    {
                        AutoReplenishment = true,
                        PermitLimit = 100,
                        Window = TimeSpan.FromMinutes(1)
                    }));
        });
    }
}

public static class ServiceCollectionExtensions

    public static IServiceCollection AddMonitoringProvider(this IServiceCollection services, IConfiguration configuration)
    {
        var providerType = configuration["MonitoringProvider"];
        return providerType?.ToLower() switch
        {
            "prometheus" => services.AddSingleton<IMonitoringProvider, PrometheusProvider>(),
            "azuremonitor" => services.AddSingleton<IMonitoringProvider, AzureMonitorProvider>(),
            _ => services.AddSingleton<IMonitoringProvider, PrometheusProvider>() // Default
        };

    {
        var providerType = configuration["HealthCheckProvider"];
        return providerType?.ToLower() switch
        {
            "local" => services.AddSingleton<IHealthCheckProvider, LocalHealthCheckProvider>(),
            "azure" => services.AddSingleton<IHealthCheckProvider, AzureHealthCheckProvider>(),
            _ => services.AddSingleton<IHealthCheckProvider, LocalHealthCheckProvider>() // Default

        _circuitBreakerPolicy = Policy
            .Handle<HttpRequestException>()
            .Or<TimeoutException>()
            .CircuitBreakerAsync(

                durationOfBreak: TimeSpan.FromSeconds(settings.BreakDurationSeconds),
                onBreak: (exception, duration) => 
                {
                    // Log circuit breaker opened
                },
                onReset: () => 
                {
                    // Log circuit breaker closed
                });
    }
    public async Task<T> ExecuteAsync<T>(Func<Task<T>> action)
    {
        return await _circuitBreakerPolicy.ExecuteAsync(action);
    }
}
Configurable Rate Limiting Implementation
ConfigurableRateLimitMiddleware.cs:
csharp
public class ConfigurableRateLimitMiddleware
{
    private readonly RequestDelegate _next;
    private readonly RateLimitConfiguration _config;
    public async Task InvokeAsync(HttpContext context)
    {
        var strategy = _config.Strategy.ToLower() switch
        {
            "user" => GetUserBasedKey(context),
            "ip" => GetIPBasedKey(context),
            "hybrid" => GetHybridKey(context),
            _ => GetIPBasedKey(context)
        };
        var rateLimitResult = await ApplyRateLimitAsync(strategy, context);
        if (!rateLimitResult.IsAllowed)
        {
            context.Response.StatusCode = 429;
            context.Response.Headers.Add("Retry-After", rateLimitResult.RetryAfter.ToString());
            await context.Response.WriteAsync("Rate limit exceeded");
            return;
        }
        await _next(context);
    }
    private string GetUserBasedKey(HttpContext context) => 
        context.User.Identity?.Name ?? context.Connection.RemoteIpAddress?.ToString() ?? "anonymous";
    private string GetIPBasedKey(HttpContext context) => 
        context.Connection.RemoteIpAddress?.ToString() ?? "unknown";
    private string GetHybridKey(HttpContext context) => 
        $"{GetUserBasedKey(context)}:{GetIPBasedKey(context)}";
}

NFRSection Completion Logic:
typescript
const calculateSectionCompletion = (section: NFRSection): SectionStatus => {
  const requiredQuestions = section.questions.filter(q => q.isRequired);
  const optionalQuestions = section.questions.filter(q => q.isOptional);
  // Check dependency satisfaction
  const dependentQuestions = section.questions.filter(q => q.dependsOn?.length > 0);
  const satisfiedDependencies = dependentQuestions.filter(q => 
    q.dependsOn.every(depId => isQuestionCompleted(depId))
  );
  return {
    required: {
      completed: requiredQuestions.filter(q => q.isCompleted).length,
      total: requiredQuestions.length
    },
    optional: {
      completed: optionalQuestions.filter(q => q.isCompleted).length,
      total: optionalQuestions.length
    },
    dependencies: {
      satisfied: satisfiedDependencies.length,
      total: dependentQuestions.length
    },
    // Section is "complete" when all required + dependencies are satisfied
    isComplete: requiredQuestions.every(q => q.isCompleted) && 
                satisfiedDependencies.length === dependentQuestions.length
  };
};

const ArchitectureCanvas = () => {
  const [selectedServices, setSelectedServices] = useState<AzureService[]>([]);
  const [autoIncludedServices, setAutoIncludedServices] = useState<AzureService[]>([]);
  const onServiceDrop = (service: AzureService) => {
    // Auto-include required dependencies
    const requiredDeps = getServicesByIds(service.requiredDependencies);
    const newServices = [service, ...requiredDeps];
    // Check for conflicts
    const conflicts = newServices.filter(newService => 
      selectedServices.some(existing => 
        existing.conflictsWith.includes(newService.id)
      )
    );
    if (conflicts.length > 0) {
      // Show conflict resolution dialog
      showConflictDialog(conflicts);
    } else {
      setSelectedServices(prev => [...prev, ...newServices]);
      // Suggest optional dependencies
      const optionalDeps = getServicesByIds(service.optionalDependencies);
      showOptionalDependenciesDialog(optionalDeps);
    }
  };
  return (
    <div className="architecture-canvas min-h-96 border-2 border-dashed border-gray-300 p-4">
      <h3>Your Architecture</h3>
      {/* Core services */}
      <div className="mb-4">
        <h4>Core Services</h4>
        {selectedServices.filter(s => s.architectureRole === 'core').map(service => (
          <ServiceNode key={service.id} service={service} />
        ))}
      </div>
      {/* Supporting services */}
      <div className="mb-4">
        <h4>Supporting Services</h4>
        {selectedServices.filter(s => s.architectureRole === 'supporting').map(service => (
          <ServiceNode key={service.id} service={service} />
        ))}
      </div>
      {/* Auto-included dependencies indicator */}
      {autoIncludedServices.length > 0 && (
        <div className="text-sm text-blue-600 bg-blue-50 p-2 rounded">
          Auto-included: {autoIncludedServices.map(s => s.name).join(', ')}
        </div>

import React, { useState } from 'react'
import { ChevronDownIcon, ChevronRightIcon, CheckCircleIcon } from '@heroicons/react/24/outline'
import { nfrSections } from '../data/nfrData'
import type { NFRSection } from '../types'
const NFRAssessmentForm: React.FC = () => {
  const [sections, setSections] = useState<NFRSection[]>(nfrSections)
  const toggleSection = (sectionId: string) => {
    setSections(sections.map(section => 
      section.id === sectionId 
        ? { ...section, isCollapsed: !section.isCollapsed }
        : section
    ))
  }
  const updateQuestion = (sectionId: string, questionId: string, value: any) => {
    setSections(sections.map(section =>
      section.id === sectionId
        ? {
            ...section,
            questions: section.questions.map(question =>
              question.id === questionId
                ? { ...question, value, isCompleted: !!value }
                : question
            )
          }
        : section
    ))
  }
  const getSectionCompletion = (section: NFRSection) => {
    const requiredQuestions = section.questions.filter(q => q.isRequired)
    const completedRequired = requiredQuestions.filter(q => q.isCompleted).length
    return {
      completed: completedRequired,
      total: requiredQuestions.length,
      isComplete: completedRequired === requiredQuestions.length
    }
  }
  return (
    <div className="space-y-4">
      {sections.map((section) => {
        const completion = getSectionCompletion(section)
        return (
          <div key={section.id} className="border rounded-lg">
            {/* Section Header */}
            <div
              className="flex items-center justify-between p-4 cursor-pointer hover:bg-gray-50"
              onClick={() => toggleSection(section.id)}
            >
              <div className="flex items-center space-x-3">
                {completion.isComplete ? (
                  <CheckCircleIcon className="w-5 h-5 text-green-500" />
                ) : (
                  <div className="w-5 h-5 rounded-full border-2 border-gray-300" />
                )}
                <div>
                  <h3 className="font-semibold">{section.title}</h3>
                  <p className="text-sm text-gray-600">
                    {completion.completed}/{completion.total} required
                  </p>
                </div>
              </div>
              {section.isCollapsed ? (
                <ChevronRightIcon className="w-5 h-5" />
              ) : (
                <ChevronDownIcon className="w-5 h-5" />
              )}
            </div>
            {/* Section Content */}
            {!section.isCollapsed && (
              <div className="px-4 pb-4 space-y-3">
                {section.questions.map((question) => (
                  <div key={question.id} className="space-y-2">
                    <label className="flex items-start space-x-2">

                        question.isRequired

                        {question.isRequired ? 'Required' : 'Optional'}

import React, { useState } from 'react'
import { useDrop } from 'react-dnd'
import { TrashIcon } from '@heroicons/react/24/outline'
import type { AzureService } from '../types'
import { getServiceById } from '../data/azureServices'
const ArchitectureCanvas: React.FC = () => {
  const [selectedServices, setSelectedServices] = useState<AzureService[]>([])
  const [autoIncluded, setAutoIncluded] = useState<string[]>([])
  const [{ isOver }, drop] = useDrop({
    accept: 'azure-service',
    drop: (service: AzureService) => {
      if (selectedServices.find(s => s.id === service.id)) {
        return // Already added
      }
      // Auto-include required dependencies
      const requiredServices: AzureService[] = []
      const autoIncludedIds: string[] = []
      service.requiredDependencies.forEach(depId => {
        if (!selectedServices.find(s => s.id === depId)) {
          const depService = getServiceById(depId)
          if (depService) {
            requiredServices.push(depService)
            autoIncludedIds.push(depId)
          }
        }
      })
      setSelectedServices(prev => [...prev, service, ...requiredServices])
      setAutoIncluded(prev => [...prev, ...autoIncludedIds])
    },
    collect: (monitor) => ({
      isOver: monitor.isOver(),
    }),
  })
  const removeService = (serviceId: string) => {
    setSelectedServices(prev => prev.filter(s => s.id !== serviceId))
    setAutoIncluded(prev => prev.filter(id => id !== serviceId))
  }
  const getServicesByRole = (role: string) => {
    return selectedServices.filter(s => s.architectureRole === role)
  }
  return (
    <div
      ref={drop}
      className={`min-h-96 border-2 border-dashed rounded-lg p-4 transition-colors ${
        isOver ? 'border-blue-400 bg-blue-50' : 'border-gray-300'
      }`}
    >
      {selectedServices.length === 0 ? (
        <div className="flex items-center justify-center h-32 text-gray-500">
          <div className="text-center">
            <p className="text-sm">Drag Azure services here</p>
            <p className="text-xs text-gray-400">Dependencies will be auto-included</p>
          </div>
        </div>
      ) : (
        <div className="space-y-4">
          {/* Core Services */}
          {getServicesByRole('core').length > 0 && (
            <div>
              <h4 className="font-semibold text-sm text-green-700 mb-2">Core Services</h4>
              <div className="space-y-2">
                {getServicesByRole('core').map((service) => (
                  <ServiceNode
                    key={service.id}
                    service={service}
                    isAutoIncluded={autoIncluded.includes(service.id)}
                    onRemove={() => removeService(service.id)}
                  />
                ))}
              </div>
            </div>
          )}
          {/* Supporting Services */}
          {getServicesByRole('supporting').length > 0 && (
            <div>
              <h4 className="font-semibold text-sm text-blue-700 mb-2">Supporting Services</h4>
              <div className="space-y-2">
                {getServicesByRole('supporting').map((service) => (
                  <ServiceNode
                    key={service.id}
                    service={service}
                    isAutoIncluded={autoIncluded.includes(service.id)}
                    onRemove={() => removeService(service.id)}
                  />
                ))}
              </div>
            </div>
          )}
        </div>
      )}
    </div>
  )
}
const ServiceNode: React.FC<{
  service: AzureService
  isAutoIncluded: boolean
  onRemove: () => void
}> = ({ service, isAutoIncluded, onRemove }) => {
  return (
    <div className={`flex items-center justify-between p-2 rounded border ${
      isAutoIncluded ? 'bg-blue-50 border-blue-200' : 'bg-white border-gray-200'
    }`}>
      <div className="flex-1">
        <div className="flex items-center space-x-2">
          <h5 className="text-sm font-medium">{service.name}</h5>
          {isAutoIncluded && (
            <span className="px-1 py-0.5 text-xs bg-blue-100 text-blue-700 rounded">
              Auto-included
            </span>
          )}
        </div>
        <p className="text-xs text-gray-600">{service.tier}</p>
      </div>
      <button
        onClick={onRemove}
        className="p-1 text-red-500 hover:text-red-700"
      >
        <TrashIcon className="w-4 h-4" />
      </button>
    </div>
  )
}
